# 60秒演示脚本

此版本用于离线录制，画面持续显示「虚构演示价格」。真实联调完成后另录真实版本，展示实际门店/方式和查询时间，不录入Token、地址、券码或账号资料。

## 0–10秒

输入「我想吃汉堡、中薯和可乐，预算30元，汉堡不要换」。展示确认后的偏好摘要。

## 10–30秒

运行README中的 compare 示例。原单36元，保留全部的候选32元；换小薯29元；只保留汉堡24元。解释各自金额与取舍。强调保留全部需要多2元预算。

## 30–45秒

输入「可乐不要动」。运行 update 示例，再将输出偏好放回输入的 preferences，重新 compare。预算优先也必须保留可乐；此演示候选中29元方案满足要求。

## 45–60秒

输入「预算最多20元」。预算方案为空，显示在当前候选与硬偏好下最少还差9元。由用户决定增加预算或解锁偏好。演示到比较结果为止，不创建订单。

## 真正的接入展示

在WorkBuddy中显示 tools/list 和经过脱敏的 query-meals、query-meal-detail、query-store-coupons、calculate-price 调用。让观众看到报价来自官方查询，而比较逻辑解释的是用户愿意接受哪些改动。失败也如实显示，不拼接假的成功记录。
